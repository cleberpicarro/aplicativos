# Site comercial do SyncTasks

Página estática (HTML e CSS, sem build), separada do app. Abrir `index.html` no navegador já mostra o site.

- Texto de base: rascunho aprovado com 7 seções (topo, solução, recursos, como funciona, planos, perguntas, contato).
- Imagens em `img/`: capturas reais do app com a equipe de exemplo (sem dados reais).
- Plano Equipe: R$ 20,00 por usuário/mês. Ainda a definir, marcados com `[colchetes]` no `index.html`: limite do plano Grátis e e-mail de contato. Política de privacidade e página de cadastro ainda não existem.
- Publicado pelo Render como site estático (serviço `synctasks-site` no `render.yaml`): https://synctasks-site.onrender.com. Os botões “Começar” levam ao app enquanto não há página de cadastro.
